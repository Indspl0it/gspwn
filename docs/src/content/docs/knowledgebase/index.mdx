pipeline. These pages document the platform it runs on, and stand on their own
as reference material.

Pages are ordered by descending abstraction. Each carries one figure, the
reference tables behind it, and one example traced end to end.

## Sourcing

Driver facts come from the headers in `open-gpu-kernel-modules`. Programming
model and toolchain facts come from the CUDA Programming Guide and the PTX ISA
specification. Constant values and struct layouts are not reproduced here.
They move between driver branches. Pages state the header a number lives in and
leave reading it to whatever needs the value.
